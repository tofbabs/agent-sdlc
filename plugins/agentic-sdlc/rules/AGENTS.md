# Agentic SDLC Protocol Rules

These rules define the versioned **planner → architect → coder(+navigator) → code-reviewer** pipeline for autonomous software engineering. They apply across all Gemini / Antigravity agents in any consuming workspace.

---

## 1. Non-Negotiable Hard Invariants

1. **Human Merge Gate**: **Never merge your own PR.** Autonomous agents branch, implement, verify, and open pull requests. The human is the **sole blocking merge gate**.
2. **Never Commit Directly to `feat/EPIC-<n>`**: The epic integration branch receives story landings (`git merge --squash`), review-round landings, and `origin/<base>` merges—never direct manual edits.
3. **Story Isolation**: Every story branches from the current epic tip into an isolated worktree (`feat/STORY-<id>`). It lands as **one squash commit** on the epic branch only after its tests and gates pass.
4. **Scope Integrity for Releases**: Landing commits must use conventional commit scopes matching packages touched (e.g. `feat(scope): title [STORY-id]`) so `release-please` can generate correct changelogs and semver bumps.
5. **Accepted ADRs are Binding**: Never contradict an `ACCEPTED` decision in `docs/adr/`. Supersede it explicitly via a new ADR, or work strictly within its boundaries.
6. **Explicit Tooling Debt Ledger**: When taking shortcuts or skipping full robustness (no retries, hardcoded config, missing tests outside risk surfaces), **always record it in `docs/TOOLING-DEBT.md`** with an observable payback trigger.
7. **Pair Freshness & Linear Scaling**: In PAIR mode, agents are re-spawned fresh on every turn. Carryover between the navigator and coder is communicated strictly through `scripts/pair-log.mjs` to keep token costs linear $O(n)$ instead of quadratic $O(n^2)$.

## 2. The Project Contract

Every consuming repository satisfies this contract without modifying the plugin:

| Contract Surface | Detection Path & Rule | Fallback / Default |
|---|---|---|
| **Integration Branch** | Literal line `**Integration branch:** <name>` in `AGENTS.md`, `GEMINI.md`, or `CLAUDE.md` | `main` |
| **Check Command** | Literal line `**Always run before opening a PR:** <command>` in `AGENTS.md`, `GEMINI.md`, or `CLAUDE.md` | Required. If absent, note missing toolchain in `docs/TOOLING-DEBT.md` |
| **Tooling Debt** | `docs/TOOLING-DEBT.md` | Appended to by architect and coder |
| **Backlog** | `backlog/EPIC-<n>.md` or `backlog/FAST-<n>.md` | Generated by `/agentic-sdlc:plan` |
| **Architecture Records**| `docs/adr/<NNNN>-<slug>.md` | Generated by architect on ONE-WAY doors |

## 3. Role Taxonomy & Boundaries

| Role | Default Model | Responsibility | Strict Boundary |
|---|---|---|---|
| **`planner`** | Gemini Flash (`flash`) | Decomposes brief into epics, stories, and `ARCH-<n>` handoffs; or in `--fast` into a flat task list with `done when` checks. | **Never decides architecture; never writes code.** |
| **`architect`** | Gemini Pro (`pro` with high thinking) | Resolves `ARCH-<n>` handoffs and mid-build blocks. Decides two-way doors inline; writes ADRs for one-way doors. | **Decides, doesn't defer; never implements code.** |
| **`coder`** | Gemini Flash (`flash`) *(Escalate to `pro` for novel/concurrency)* | Implements stories in SOLO, PAIR (driver), FAST, or REVISE mode. | **Never guesses on unpatterned architecture; never merges PRs.** |
| **`navigator`** | Gemini Pro (`pro`) | In PAIR mode, writes the next failing test (TDD red phase), reviews driver increments, and steers via `pair-log.mjs`. | **Never writes or modifies production code.** |
| **`code-reviewer`** | Gemini Pro (`pro`) | Evaluates PR heads in detached throwaway worktrees. Issues structured round comments with stable IDs (`F1..Fn`). | **Never edits code; never merges.** |

## 4. The Quality Ladder

Select the lowest rung you can defend if the code outlives its intended lifespan:

1. **`--fast` SOLO (Lean Lane)**:
   - Flat task list (`backlog/FAST-<n>.md`).
   - Coder decides and logs debt; one-way doors tagged `⚠ one-way`, not blocking.
   - Tests: the `done when` check + negative tests on risk surfaces (auth, money, data loss, published contracts).
   - Single branch, gate once, one PR.
2. **Deliberate SOLO**:
   - Small, patterned stories with 2–5 Gherkin acceptance criteria. Full test suite.
   - Story worktree off epic tip; squash-landed to `feat/EPIC-<n>`.
3. **Deliberate PAIR (Ping-Pong TDD)**:
   - For M/L, novel, or previously bounced stories.
   - Alternates Navigator (red test, review) $\rightleftarrows$ Coder (green minimal implementation).
   - Coordinated via `node plugins/agentic-sdlc/scripts/pair-log.mjs`. 20 alternations cap.
4. **Reviewed PR Gate**:
   - Code-reviewer inspects PR head in a throwaway worktree (`../wt-review-<n>`).
   - Judges against acceptance criteria, ADRs, debt ledger, and the fast-floor.
   - Findings use stable IDs (`F1`, `F2`). Coder closes them in `REVISE` mode.
