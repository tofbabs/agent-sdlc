# Agentic SDLC: Review (`/agentic-sdlc:review`)

Use this skill to review any open pull request generated by the pipeline.

## Invocation & Arguments

```bash
/agentic-sdlc:review <PR-number> [--pro]
```

- **Target**: Pull request number (`42`).
- **`--pro` Flag**: Default model is `gemini-pro`. If high-stakes security/contract surfaces are modified, ensure maximum reasoning depth is allocated.

---

## Workflow Steps

### Step 1: Gather PR Facts
Run via shell:
```bash
gh pr view <n> --json state,headRefName,baseRefName,headRefOid,body,reviews,comments,commits
gh pr checks <n>
```
- Verify state is `OPEN`.
- Identify if `Mode: FAST` is set in the PR body.
- Extract story IDs from commits (e.g. `[STORY-1-1]`).
- Determine highest existing review round `k` from `## Review — round <k>` comments.

### Step 2: Guard Against Redundant Spawns
- If round `k >= 1`, head sha equals round `k` reviewed sha, and no `## Response — round k` exists:
  **Stop** — report `"already reviewed at <sha>, awaiting coder response"`.
- If `k >= 4` with persistent `REQUEST_CHANGES`:
  **Stop** — report `"round cap reached — escalate to human"`.

### Step 3: Create Detached Worktree
```bash
git fetch origin <head-branch>
git worktree remove ../wt-review-<n> 2>/dev/null || true
git worktree add --detach ../wt-review-<n> origin/<head-branch>
```
*(Never run `gh pr checkout` in the active repository checkout).*

### Step 4: Spawn Code-Reviewer Agent
Spawn the **code-reviewer** subagent (`model: pro`):
- **Worktree**: `../wt-review-<n>`.
- **Guidelines**: Read `plugins/agentic-sdlc/agents/code-reviewer.md`.
- **Fast Mode Floor**: If `Mode: FAST` is active, read `plugins/agentic-sdlc/reference/review-fast-floor.md` before generating findings. Missing unit tests on non-risk surfaces are acceptable; missing negative tests on auth/money/data-loss/contracts are blocker findings.
- **Verification**: Verify that every story acceptance criterion maps to a test that would FAIL without this diff. Check ADR compliance and ensure undocumented shortcuts are logged to `docs/TOOLING-DEBT.md`.

### Step 5: Post Review & GitHub Verdict
Reviewer formats the exact round comment structure:
```markdown
## Review — round <k>
- verdict: REQUEST_CHANGES | APPROVE
- reviewed sha: <head-sha>

- F1: <severity> — <issue> — <required fix>
- F2: <severity> — <issue> — <required fix>
```

Post via GitHub CLI:
```bash
gh pr review <n> --request-changes --body "<the round comment>"
# OR
gh pr review <n> --approve --body "<the round comment>"
```
*(If the reviewing identity authored the PR, fallback to `gh pr review <n> --comment --body "..."`).*

### Step 6: Clean Up Worktree
Always remove the throwaway worktree:
```bash
git worktree remove ../wt-review-<n>
```

### Step 7: Next Step Report
- If `REQUEST_CHANGES`: Notify user to run `/agentic-sdlc:build` (REVISE loop).
- If `APPROVE`: State **"Ready for human merge — the human owns the merge gate."**
